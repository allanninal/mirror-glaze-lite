== Description ==

A refined, editorial block theme for pâtisseries and pastry shops. Patterns for the collection by category with prices and seasonal notes, the season’s limited pieces, bespoke gâteau commissions, the pastry chef’s story and how the atelier works, a gallery, opening hours and how to find you, all editable in the Site Editor.

Mirror Glaze Lite is a block theme: every page, header and footer is edited in the Site Editor, with no page builder. The front page is built from patterns you can rearrange, and each section is also in the pattern inserter for any page.

A contact form is plugin territory: for a form on your contact page, install a form plugin from WordPress.org.

The full version of Mirror Glaze adds a one-click demo import (pages, menu, photos and journal posts), a WooCommerce shop set up with products and photos, a dark style and a setup guide: https://checkout.freemius.com/theme/43998/plan/77513/

== Frequently Asked Questions ==

= Does the theme collect any data? =

No. Mirror Glaze Lite sets no cookies and uses no tracking. To offer updates it asks GitHub (api.github.com) for the latest release of github.com/allanninal/mirror-glaze-lite, at most twice a day; that request carries nothing about your site. The upgrade notice in the dashboard is a plain link; dismissing it is stored on your own site.

= How do I update it? =

Like any theme: new versions appear under Dashboard › Updates. Each version is also a release at https://github.com/allanninal/mirror-glaze-lite/releases, with the theme zip attached. Install that zip, not GitHub's "Source code" download, whose folder name is different.
